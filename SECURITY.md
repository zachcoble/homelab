# Security

This is a personal portfolio/documentation repo for a home lab, not a maintained software project. There's no code here that takes external input, so there's no active security support.

- No secrets, credentials, or real network addresses are committed — see the README for what's intentionally redacted.
- If you spot something that looks like a real credential or address slipped in by mistake, please open an issue and I'll rotate/remove it immediately.
